1차 업무 추가 요청-이미지 전처리, 이상치 필터링



\[기본 문제]

\-크기조정: AI모델 표준 입력 사이즈인 224X224로 변환

\-색상변환: 흑백으로 변경하고 숫자범위를 일정하게 맞추어 데이터 단순화

\-노이즈제거: 패턴을 잘 보이게 하기 위해 잡음을 제거

\-데이터증강: 이미지 변형으로 학습형 데이터 증가



\[심화문제]

\-너무 어두운 이미지 제거: 검은 화면이면 특징이 안보여서 학습 가치가 낮음 

\-객체 크기가 너무 작은 이미지 제거: 객체 정보가 너무 적어서 학습이 어려움



\[제출항목]

\-image\_preprocessing.py: 전처리 코드

\-preprocessed\_samlples: 처리된 이미지 5장 저장

\-README.md: 전처리 과정 설명
